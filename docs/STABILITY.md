# 1.0.3：登录启动与休眠恢复

此版本针对“开机不能自启”和“休眠后任务栏显示消失”修复启动与显示生命周期。显示仍是 Explorer 任务栏内的原生子窗口，默认左下角。

## 修复内容

- 自启动从当前用户的 Run 注册表项迁移至当前用户的登录计划任务。登录后等待 5 秒启动，以普通用户权限运行；使用电池时也允许启动及继续运行，不要求空闲或网络，没有最长运行时间限制。任务配置失败时保留旧启动项并记录原因。
- 安装器在采集服务配置完成后登记登录任务，并检查配置进程的结果。原来的启动步骤在服务就绪标记设置之前已被跳过，此顺序已修正；勾选自启动时安装完成即可启动常驻任务。
- 登录任务启动一个轻量监督进程。显示进程意外退出后等待 3 秒重启；界面连续多次无响应时重启本应用显示进程。托盘“退出”会同时结束监督和显示，不会再次拉起；关闭自启动会移除登录任务。
- 收到电源恢复、会话解锁或 Explorer 重建通知时，清除旧读数与任务栏边界缓存，重新创建显示和托盘、连接采集服务，并在 20 秒内持续重试挂载。定时器长时间暂停后的首个刷新也会触发恢复。
- 任务栏 UI Automation 查询移至本应用的独立辅助进程。原来的后台查询可能永久卡住，导致缓存过期后显示一直隐藏；现在每次查询最多等待 6 秒，超时后终止并重建辅助进程，下一轮继续查询。过期查询结果不能覆盖恢复后的边界缓存。
- 采集连接在 6 秒未收到快照时重连；恢复后的旧连接不能覆盖新快照。采集服务及 CPU 核显扣除口径沿用 1.0.2。
- 两行显示宽度缩至 220 DIP，保留固定数字字体和完整 CPU／GPU 位置。本机更新时左侧安全空位比旧窗口仅少 2 个物理像素，旧版因此整块隐藏；收紧多余留白后可在当前空位中显示，并继续避开任务栏按钮。

## 使用与排查

安装时勾选“登录后自动启动 BatteryHelper”。也可在托盘菜单或详情设置中启用“登录时自动启动”。计划任务名称以 `BatteryHelper-` 开头，动作指向正式安装目录的 `BatteryHelper.exe --supervise`。

选择“退出”会结束本次运行；下一次登录仍按自启动设置启动。暂时不想显示功率时选择“隐藏任务栏功率”，采集与恢复继续工作。

本应用的生命周期日志位于 `%LOCALAPPDATA%\BatteryHelper\lifecycle.log`，超过 512 KiB 后轮换为上一份日志。日志记录启动配置、恢复原因、辅助查询超时和意外退出，不记录令牌或凭据。

## 本机验证范围

2026-10-12 在 HONOR XWC-P / Core Ultra X7 358H / Arc B390、Windows 11、200% 缩放下验证。46 项自动检查通过，其中新增登录任务配置检查，覆盖电池运行、普通权限、登录触发、无时间限制以及带空格的程序路径。

使用计划任务实际启动普通用户进程；模拟电源恢复通知后，显示重新挂载，采集重新连接，任务栏截图确认功率文字可见。故意挂起本应用的任务栏查询辅助进程后，6 秒超时机制重建查询，随后显示恢复；强制结束显示进程后，监督进程启动新显示实例，计划任务仍在运行。主动退出后所有本应用显示、监督与查询进程停止，计划任务成功返回。

正式安装包的安装结果、计划任务配置和实际显示检查记录在 [VALIDATION.md](VALIDATION.md) 的 1.0.3 部分。截图与精简检查结果随源码包交付，完整调试记录留在本地。

本轮没有强制注销、重启或休眠用户电脑。模拟恢复通知验证了恢复代码路径，实际休眠／休眠唤醒及下一次登录启动仍需要用户日常使用验收；也没有重新完成 30 分钟界面持续测试。
